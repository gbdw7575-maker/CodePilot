# 测试RAG功能：校园日常动漫跨作品故事集（第二弹）

## 故事一：《辉夜大小姐想让我告白×冰菓×果然我的青春恋爱喜剧搞错了：秀知院古籍研究部的密室事件》

**角色：** 四宫辉夜、白银御行、藤原千花、石上优（辉夜大小姐想让我告白）；折木奉太郎、千反田爱瑠、福部里志、伊原摩耶花（冰菓）；比企谷八幡、雪之下雪乃、由比滨结衣（果然我的青春恋爱喜剧搞错了）

**故事：**

秀知院学园与总武高中、神山高中三校联合举办“文化祭交流周”，三校的学生会成员被安排在同一栋旧校舍里筹备联合展览。旧校舍三楼有一间被封了二十年的“古籍研究室”，门上贴着封条，但封条在前一天晚上被人撕开了。

四宫辉夜第一个发现了异常。她站在门口，眉头微皱——封条断裂的方式很整齐，像是被人用刀片裁开的，而不是撕开的。白银御行赶来时，藤原千花已经钻进了房间，在里面大喊：“好厉害！好多旧书！还有一台留声机！”石上优站在门口不敢进去，嘟囔着“这种展开肯定是恐怖片”。

折木奉太郎是被千反田爱瑠拉来的。千反田睁着那双好奇的大眼睛说：“折木同学，我很好奇！”折木叹了口气，但他注意到了一件事：房间里的灰尘分布不均匀，靠窗的书架灰尘很薄，而靠门的书架灰尘很厚。这说明有人最近只翻过靠窗的书架。

比企谷八幡是被由比滨结衣拖来的。雪之下雪乃冷静地观察着房间，她发现留声机的唱针上还残留着新鲜的划痕，说明最近有人用过它。比企谷则蹲在角落，看着地板上几道浅浅的拖痕说：“这间房间……有人经常来。”

八人（加上藤原和千反田就是十人）开始调查。石上优发现了一本日记，封面上写着“古籍研究部·最终记录”。日记的最后一页写着：“我们发现了不该发现的东西。如果有人看到这本日记，请立刻离开这间房间。”

藤原千花兴奋地翻开留声机旁的唱片，放上去，留声机居然响了。传出的不是音乐，而是一段录音：“……第三书架……背后……不要相信……”录音到这里断了。

千反田立刻跑到第三书架前。折木想阻止但没来得及——千反田推了一下书架，书架居然转动了，露出一个暗格。暗格里有一封信和一把钥匙。信上写着：“钥匙能打开地下室的门。但地下室里的东西，会改变你们对这座学校的看法。”

辉夜的眼睛亮了。白银推了推眼镜，两人同时想到了什么。辉夜说：“这封信的笔迹……和校长室的某份文件很像。”白银点头：“而且这把钥匙的样式，是二十年前秀知院旧校舍的通用钥匙。”

比企谷突然说：“等一下。这封信是写给‘发现者’的。但为什么要把信放在暗格里，而不是直接放在日记里？因为写这封信的人……不想让所有人看到。只让‘能发现暗格的人’看到。”

雪之下接话：“而能发现暗格的人，必须满足三个条件：知道第三书架有问题、有勇气推书架、足够细心注意到灰尘的差异。这说明写信的人……在筛选。”

十人决定去地下室。地下室的门在旧校舍最底层，一把生锈的铁锁锁着。辉夜用钥匙打开锁，门后是一条长长的走廊。走廊尽头是一间教室大小的房间，里面摆满了旧课桌和旧椅子。墙上贴满了照片——是二十年前秀知院、总武高中、神山高中的学生合照。

福部里志突然指着一张照片说：“这个人……是我爸爸。”伊原摩耶花也指着一张照片：“这个是我妈妈。”由比滨结衣惊讶地说：“我妈妈也在！”比企谷看着照片上的一个男人，沉默了。

折木拿起一张照片，照片背面写着：“三校联合文化祭·第一届·二十年前”。他翻到另一张照片，背面写着：“我们发现了学校的秘密。三校的创办人……是同一个人。”

千反田倒吸一口气。辉夜和白银对视一眼——秀知院的创办人四宫家、总武高中的创办人雪之下家、神山高中的创办人千反田家……这三个家族，在二十年前曾经秘密会面，签署了一份文件。文件的内容是：三校联合，建立一个“特殊教育区”，但后来因为某种原因失败了。

雪之下雪乃轻声说：“我听说过这件事。我母亲提过，二十年前三校差点合并，但因为一场事故……有人死了。”

地下室最里面有一张桌子，桌上放着一份文件。文件上写着：“三校合并计划·最终方案”。方案的最后一行写着：“如果计划失败，所有参与者将删除记忆。但记忆不能被删除，只能被封印。封印的钥匙，就是古籍研究部。”

比企谷说：“所以，这间房间是二十年前某个人留下的。他不想让这件事被忘记，但他也不能直接说出来。所以他设了一个谜题，等有人来发现。”

折木说：“而这个人……现在就在我们中间。”他看着福部里志、伊原摩耶花、由比滨结衣——他们的父母都是二十年前的参与者。而辉夜、白银、雪之下、千反田——他们的家族是创办者。

辉夜沉默了很久，然后说：“所以，我们十个人聚在这里，不是偶然。”

白银握住她的手：“但我们可以选择。二十年前的人选择了封印。我们可以选择面对。”

十人将文件放回原处。他们决定不公开这件事，但他们会记住。古籍研究部的门被重新封上，但这次，封条上多了一行字：“真相在这里，等下一代人来发现。”

## 故事二：《轻音少女×孤独摇滚×BanG Dream!：轻音部、结束乐队与Roselia的联合演出》

**角色：** 平泽唯、秋山澪、田井中律、琴吹紬、中野梓（轻音少女）；后藤一里、伊地知虹夏、山田凉、喜多郁代（孤独摇滚）；凑友希那、冰川纱夜、今井莉莎、宇田川亚子、白金燐子（BanG Dream!）

**故事：**

樱丘女子高中、下北泽高中、羽丘女子学园三校联合举办“校园音乐节”。轻音部、结束乐队、Roselia被安排在同一天演出。但问题来了：三支乐队只有一间练习室，而且练习室的门锁坏了，只能从里面打开。

平泽唯第一个到，她带着吉他“吉太”走进练习室，然后不小心把门关上了。门锁咔嗒一声，从外面打不开了。秋山澪和田井中律赶来时，只听到唯在里面喊：“门打不开了！”律试着推门，推不动。澪拿出手机，但练习室在地下室，没有信号。

琴吹紬和中野梓随后赶到。紬说：“我带了蛋糕。”梓说：“我带了备用弦。”律说：“这些都不能开门啊！”

这时，后藤一里背着吉他走过来。她看到门口围了一群人，立刻缩到墙角，开始碎碎念：“怎怎怎怎么办……我是不是不该来……我这种人就应该在家里蹲着……”伊地知虹夏把她拉起来：“小孤独！振作一点！”山田凉冷静地说：“门锁坏了，需要工具。”喜多郁代说：“我去找老师！”

喜多刚跑出去，凑友希那带着Roselia成员来了。友希那看了一眼门，说：“用蛮力。”冰川纱夜说：“不行，会损坏门。”今井莉莎说：“我试试用发卡。”宇田川亚子说：“让莉莎亲用魔法！”白金燐子小声说：“我可以试试用电子琴的频率……”

莉莎用发卡撬锁，发卡断了。亚子用鼓棒敲锁，锁没坏，鼓棒弯了。燐子用电子琴弹了一个高频音，锁没反应。友希那说：“我来。”她后退两步，准备撞门。纱夜拉住她：“友希那，你是主唱，不能受伤。”

这时，唯在里面说：“啊，我看到一把钥匙！”所有人安静下来。唯说：“在钢琴上面，有一把钥匙！”紬说：“那是练习室的备用钥匙！”唯伸手够钥匙，够不到。澪说：“唯，你踩在椅子上。”唯踩上椅子，椅子晃了一下，她摔了下来，但手里抓着钥匙。

唯把钥匙从门缝底下塞出来。律捡起钥匙，打开门。唯坐在地上，吉太压在她身上，但她笑着说：“太好了，门开了！”

十一个人挤进练习室。练习室很小，只能容纳一支乐队。虹夏说：“这样不行，我们得轮流练习。”友希那说：“不，我们一起练习。”一里缩在角落：“一起……一起练习？”凉说：“好主意。我们可以合奏。”梓说：“合奏什么？”唯说：“《相遇天使》！”一里说：“我……我不会……”友希那说：“那就学。”

于是，三支乐队开始合奏。唯教一里弹《相遇天使》的前奏，一里教友希那弹《吉他与孤独与蓝色星球》的副歌，友希那教唯唱《Black Shout》的高音。澪和莉莎讨论贝斯线，律和亚子比拼鼓点，紬和燐子交流键盘，梓和纱夜切磋吉他，虹夏和喜多在旁边打拍子。

合奏很混乱。唯弹错了和弦，一里紧张到手指僵硬，友希那的高音破音了。但她们笑了。律说：“这才是音乐！”凉说：“不，这是噪音。”虹夏打了凉一下：“凉，不要说实话！”

演出当天，三支乐队分别表演，但最后一首歌，十一个人一起上台。唯弹吉他，一里弹吉他，友希那唱歌，澪弹贝斯，莉莎弹贝斯，律打鼓，亚子打鼓，紬弹键盘，燐子弹键盘，梓弹吉他，纱夜弹吉他。虹夏和喜多在台下挥舞荧光棒。

她们演奏的是《相遇天使》——但歌词被改了。唯唱：“我们在练习室相遇/门锁坏了/但我们打开了心扉。”一里唱：“我害怕人群/但你们让我知道/我不是孤独的。”友希那唱：“音乐不是竞争/音乐是相遇。”

台下的人哭了。台上的人笑了。

## 故事三：《月刊少女野崎君×日常×幸运星：漫画部、时定高中与陵樱学园的联合校刊》

**角色：** 野崎梅太郎、佐仓千代、御子柴实琴、堀政行、鹿岛游（月刊少女野崎君）；相生祐子、长野原美绪、水上麻衣、东云名乃、博士（日常）；泉此方、柊镜、柊司、高良美幸（幸运星）

**故事：**

野崎梅太郎的漫画连载需要新素材。佐仓千代提议：“我们可以去其他学校参观！”御子柴实琴说：“我认识时定高中的人。”堀政行说：“陵樱学园也有漫画部。”鹿岛游说：“那就三校联合校刊！”

于是，野崎、佐仓、御子柴、堀、鹿岛来到时定高中。相生祐子第一个冲出来：“哇！是漫画家！”长野原美绪拉住她：“祐子，不要跑！”水上麻衣淡定地说：“麻衣麻衣。”东云名乃说：“我是机器人。”博士说：“我是博士！”

野崎拿出笔记本，开始记录。他画下祐子摔倒的姿势，美绪吐槽的表情，麻衣沉默的样子，名乃头上的发条，博士的身高。佐仓说：“野崎君，你是来参观的，不是来画漫画的！”野崎说：“这也是参观。”

他们又来到陵樱学园。泉此方正在打游戏，柊镜在看书，柊司在吃点心，高良美幸在算数学题。此方看到野崎，说：“你是那个画少女漫的？”野崎说：“你怎么知道？”此方说：“我妹妹是你的粉丝。”镜说：“此方，不要一边打游戏一边说话。”司说：“姐姐，点心要凉了。”美幸说：“根据统计，三校联合校刊的阅读率会提高百分之三十。”

野崎又开始记录。他画下此方打游戏的姿势，镜吐槽的表情，司吃点心的样子，美幸算数学题的侧脸。堀说：“野崎，你画这么多，校刊放得下吗？”野崎说：“放不下就出增刊。”

鹿岛说：“那我们开始做校刊吧！”御子柴说：“我来排版！”佐仓说：“我来写文章！”祐子说：“我来画插图！”美绪说：“我来吐槽！”麻衣说：“……”名乃说：“我来打印。”博士说：“我来吃点心。”

校刊的内容很混乱。野崎画了漫画，但画的是“时定高中日常”和“陵樱学园日常”。祐子画了插图，但画的是“野崎君摔跤”。美绪写了吐槽，但吐槽的是“为什么我要做校刊”。此方写了游戏攻略，但攻略的是“如何在校刊截稿日前通关”。镜写了书评，但书评的是“如何应对不靠谱的搭档”。司写了点心食谱，但食谱是“如何在一分钟内吃完点心”。美幸写了统计报告，但报告是“三校联合校刊的失败概率”。

校刊印出来后，三校学生都看不懂。但野崎说：“这才是青春。”佐仓说：“野崎君，青春不是混乱。”野崎说：“青春就是混乱。”

## 故事四：《中二病也要谈恋爱×我妹妹哪有这么可爱×埃罗芒阿老师：社团联合会的秘密会议》

**角色：** 富樫勇太、小鸟游六花、丹生谷森夏、凸守早苗（中二病也要谈恋爱）；高坂京介、高坂桐乃、五更琉璃、新垣绫濑（我妹妹哪有这么可爱）；和泉正宗、和泉纱雾、山田妖精、千寿村征（埃罗芒阿老师）

**故事：**

三所学校的社团联合会决定联合举办“文化祭联合展览”。富樫勇太作为原中二病患者，被推选为学生代表。小鸟游六花坚持要带上“邪王真眼”。丹生谷森夏想阻止但失败了。凸守早苗喊着“DEATH”跟来了。

高坂京介是被妹妹桐乃逼来的。桐乃说：“我的新作要参展！”五更琉璃带着她的“黑猫”人设来了。新垣绫濑说：“我只是来监视桐乃的。”

和泉正宗是被山田妖精拉来的。妖精说：“我的新作要碾压所有人！”千寿村征说：“我只是来观察人类。”和泉纱雾躲在家里，但正宗说：“纱雾，你必须出门。”纱雾说：“我……我讨厌人群。”

十二人在联合展览的会议室相遇。六花立刻摆出姿势：“邪王真眼，启动！”森夏捂住她的嘴：“对不起，她有点中二。”早苗说：“凸守是六花大人的守护者！”桐乃说：“这是什么中二病集会？”琉璃说：“黑猫在此。”绫濑说：“桐乃，不要和奇怪的人说话。”妖精说：“我的新作是《中二病与妹妹与埃罗芒阿老师的联合展览》。”千寿村征说：“这个标题太长了。”正宗说：“纱雾，你还好吗？”纱雾躲在正宗身后，小声说：“我……我想回家。”

勇太叹了口气。他曾经也是中二病，但他现在想做一个普通高中生。他看着六花，六花正用“邪王真眼”观察会议室。他看着桐乃，桐乃正用手机写小说。他看着妖精，妖精正用笔记本写新作。他看着纱雾，纱雾正用平板画画。

勇太说：“我们……都是创作者。”所有人安静下来。勇太继续说：“中二病、妹妹、埃罗芒阿老师……这些都是我们的‘设定’。但设定不是假的。设定是我们想成为的人。”

六花说：“邪王真眼……是真的。”森夏说：“六花，那是美瞳。”六花说：“美瞳也是真的。”

桐乃说：“我的小说……是真的。”琉璃说：“我的黑猫……是真的。”绫濑说：“桐乃，你的小说是妹控小说。”桐乃说：“妹控也是真的。”

妖精说：“我的新作……是真的。”千寿村征说：“你的新作是抄袭。”妖精说：“抄袭也是真的。”正宗说：“妖精，不要承认啊！”纱雾说：“我的画……是真的。”

勇太说：“所以，我们不用隐藏。中二病、妹控、埃罗芒阿老师……这些都是我们。我们可以在联合展览上，展示真正的自己。”

十二人决定合作。六花和早苗负责“中二病展区”，桐乃和琉璃负责“妹控展区”，妖精和千寿村征负责“轻小说展区”，纱雾负责“插画展区”，勇太和森夏负责“普通展区”（虽然森夏说“普通才是最不普通的”），京介和绫濑负责“吐槽展区”。

展览当天，中二病展区排了长队，妹控展区被女生包围，轻小说展区被男生包围，插画展区被所有人包围。普通展区没人，但森夏说：“这才是真正的普通。”吐槽展区只有京介和绫濑，但他们吐槽得很开心。

折木说：“我很好奇……为什么一个章鱼老师会来参加毕业考试。”千反田说：“折木同学，我很好奇！”折木说：“千反田，不要学我说话。”

雾羽渚说：“我们是来参加毕业考试的。”濑良海斗说：“但我们不知道考什么。”白崎伊莉丝说：“我只想回家。”花冈翼说：“伊莉丝，不要这样。”

赤羽业说：“杀老师，你知道考什么吗？”杀老师说：“我知道！考……考……暗杀！”茅野枫说：“杀老师，这不是暗杀考试。”杀老师说：“但暗杀也是考试。”潮田渚说：“杀老师，你只是想被暗杀。”

考试开始。旧校舍的黑板上出现了一行字：“最终考试：找出旧校舍的秘密。”折木说：“又是秘密。”千反田说：“折木同学，我很好奇！”折木说：“我知道。”

福部里志说：“旧校舍的秘密……我听说过一个传说。”伊原摩耶花说：“什么传说？”福部说：“旧校舍的地下室，藏着一台时间机器。”摩耶花说：“里志，那是科幻。”福部说：“但传说就是传说。”

雾羽渚说：“时间机器？”濑良海斗说：“不可能。”白崎伊莉丝说：“如果是真的，我想回到过去。”花冈翼说：“伊莉丝，过去不一定比现在好。”

杀老师说：“时间机器！我要回到过去！我要阻止自己变成章鱼！”潮田渚说：“杀老师，你本来就是章鱼。”杀老师说：“渚，不要拆穿我。”

折木开始推理。他观察了旧校舍的结构，发现地下室的入口被书架挡住了。书架上的书排列整齐，但有一本书是倒着的。折木把书抽出来，书架转动，露出地下室入口。

所有人进入地下室。地下室里有一台旧机器，上面写着“时间机器·试作型”。机器旁边有一本日记。日记上写着：“我是旧校舍的建造者。我建造了时间机器，但我没有使用。因为我知道，改变过去会改变现在。但现在……我后悔了。”

千反田说：“他后悔什么？”折木说：“他后悔没有改变过去。”赤羽业说：“所以他想让我们改变过去？”杀老师说：“不，他想让我们选择。”

潮田渚说：“选择什么？”杀老师说：“选择是否使用时间机器。”茅野枫说：“如果我们使用，会改变什么？”折木说：“会改变一切。”

雾羽渚说：“我们……不需要时间机器。”濑良海斗说：“为什么？”雾羽渚说：“因为我们有未来。”白崎伊莉丝说：“但我的过去……”雾羽渚说：“伊莉丝，过去不能改变，但未来可以。”花冈翼说：“渚说得对。”

杀老师说：“我也不需要时间机器。因为我现在是章鱼，但我很开心。”潮田渚说：“杀老师，你终于承认你是章鱼了。”杀老师说：“渚，不要拆穿我。”

折木说：“我也不需要。因为过去就是过去。”千反田说：“折木同学，你说了句好话。”折木说：“我只是不想用。”

所有人决定不使用时间机器。他们离开地下室，回到教室。黑板上的字变了：“考试结束。所有人通过。”

杀老师说：“我们通过了！”潮田渚说：“杀老师，我们什么都没考。”杀老师说：“但我们选择了。”赤羽业说：“选择就是考试。”茅野枫说：“那我们考了什么？”折木说：“考了‘是否使用时间机器’。”千反田说：“折木同学，我很好奇……你会用吗？”折木说：“不会。”千反田说：“为什么？”折木说：“因为用了会改变现在。而现在的你……很好。”

千反田脸红。福部说：“折木，你说了句好话。”摩耶花说：“里志，不要拆穿他。”

杀老师说：“毕业快乐！”所有人说：“毕业快乐！”杀老师说：“等等，我们还没毕业。”潮田渚说：“杀老师，不要拆穿。”
