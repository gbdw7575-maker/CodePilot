# 接口与事件

机器可读契约由 `doc/scripts/build-contracts.cjs` 生成，公开版本保留原路径以兼容后端契约测试和前端类型生成。

- [HTTP OpenAPI](../doc/项目文档/openapi.json)
- [事件Schema](../doc/项目文档/events.schema.json)
- [工具Schema](../doc/项目文档/tools.schema.json)
- [契约正反例](../doc/项目文档/examples.json)
- [前端生成类型](../frontend/src/api/schema.d.ts)

模型工具调用经过统一Dispatcher、参数Schema、授权及风险审批。写接口沿用本地客户端标记及相关幂等、版本前提；以实际OpenAPI和实现为准。

事件可持久化补拉，用于恢复任务视图和关联模型、工具、审批、验证及错误。Trace为本地Run关联实现，不宣称已接入分布式APM平台。

任务强成功、上游消费、集成和主Run收尾使用实际交付与检查凭据；凭据过期、缺失或当前工作区漂移会拒绝推进成功。
