## PostgreSQL与后端测试

测试实际连接PostgreSQL，配置在 `backend/src/test/resources/application.yml`。使用专用空测试库，通过 `DB_TEST_URL`、`DB_TEST_USER`、`DB_TEST_PASSWORD` 指定；create-drop及测试schema清理会修改测试库，不能使用业务库。

在同一Docker网络中准备测试PostgreSQL后，从仓库根运行：

```powershell
docker run --rm --network <测试网络> -e DB_TEST_URL=jdbc:postgresql://<测试PG服务名>:5432/dsh_test -e DB_TEST_USER -e DB_TEST_PASSWORD -v "${PWD}:/workspace" -w /workspace/backend maven:3.9-eclipse-temurin-21 mvn -B test
```

部分夹具含Windows路径或本地环境前提，需要按实际测试环境核对。Runner替身／local测试模式与真实Docker围栏控制分开计数；全部模型／安全边界不能由单元测试替代。本次上传不宣称在所有操作系统上重新验收。

RAG阈值测试保留所需示例语料，放在 `backend/src/test/resources/rag-fixtures`；公开快照仅调整该测试的输入路径，不改变检索实现。

## 契约与前端

以下命令均在Docker中执行，构建目录只挂载当前仓库：

```powershell
docker run --rm -v "${PWD}:/workspace" -w /workspace node:24-alpine node doc/scripts/verify-contracts.cjs
docker run --rm -v "${PWD}:/workspace" -w /workspace/frontend node:24-alpine sh -c "npm ci && npm run build && npm run test:event-replay"
```
